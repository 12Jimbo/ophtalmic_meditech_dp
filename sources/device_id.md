# Device identity and innovation data sources

_Last reviewed: 2026-09-26_

This comparison evaluates sources for identifying ophthalmic diagnostic technologies, manufacturers, inventions, and EU market registrations. Scores are relative to this portfolio project, from **1 (weak)** to **5 (excellent)**. “$0 access” means that the publisher does not charge for the stated access path; cloud compute, storage, and engineering time can still cost money.

## Decision summary

| Goal | Recommended source | Why |
|---|---|---|
| Fastest AE-focused MVP | **Google Patents Public Data** | Immediate SQL access, global coverage and rich relational/nested modelling with minimal ingestion friction. |
| Strongest DE-focused MVP | **EPO OPS** | Official European source and the deepest ingestion engineering: OAuth, XML, quotas, incremental events and entity resolution. |
| Best EU device master and most domain-aligned MVP | **EUDAMED**, conditional on a partitioning spike | Official EU device data, successful authentication-free API access and rich device/actor/reference models. The remaining risk is complete extraction around the apparent 1,000-record cap. |
| Patent-to-science graph | **The Lens**, only after access approval | Valuable linked scholarly data, but the access decision must precede architecture. |

## Recommended boundary

For a one-source first release, **EUDAMED is now the preferred domain-aligned candidate**. It describes regulated devices actually registered for the EU market and exposes a working public API with rich device, actor and reference data. Before fixing the architecture, prove that the ophthalmic cohort can be extracted completely by partitioning requests by EMDN code and, where necessary, risk class, manufacturer or market country. The spike must detect capped partitions, deduplicate overlapping results, preserve raw responses and verify stable identifiers across repeated snapshots. Choose EPO OPS instead when patent intelligence or a globally scoped invention model is the primary objective.

A defensible ophthalmic cohort should be classification-led, using CPC groups such as A61B 3/00 (eye examination), A61B 3/102 (ophthalmic OCT), A61B 3/12 and A61B 3/14 (fundus examination and eye photography), and A61B 3/16 (tonometry), with keywords used for refinement rather than as the sole selection method.
